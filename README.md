# Personal Portfolio Website

Welcome to my personal portfolio website! 👋

This portfolio website showcases my skills, projects, education, experience, and achievements as a Computer Science Engineering student.

## 🚀 About the Project

This is a responsive personal portfolio website designed to present my professional profile and technical skills in a simple, clean, and user-friendly way.

The website includes information about my background, technical skills, projects, education, and contact details.

## ✨ Features

* 🏠 Home section
* 👩‍💻 About Me section
* 🛠️ Skills and Technologies
* 📂 Projects section
* 🎓 Education details
* 📜 Certificates and achievements
* 📞 Contact section
* 📱 Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
